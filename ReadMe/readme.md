## Hover Playground Project

## Overview

An interactive javascript DOM project where animated words appear at the mouse position whenever the user moves inside the yellow area. The project also includes a reset button and dark mode toggle for theme switching. This project was built to understand event handling, DOM manipulation, dynamic element creation, CSS animation and interactive UI behaviour.

## Features

- Hover counter
- Random words generation
- Random text colors
- Random text sizes
- Floating animation effect
- Mouse position tracking (offsetX, offsetY)
- Reset functionality
- Dark/light mode toggle
- Responsive design

## Demo

Move your mouse inside the yellow box and:

- New words appear dynamically
- Words appear exactly at the mouse position
- Each word has random color and size
- Text floats upward and fades out
- Hover count increases automatically

## Random Background Changer Project with Customizable Time Delay

## Overview

A simple & interactive web project that dynamically changes the background colour at a customizable interval built using HTML, CSS and Javascript. This project is perfect for beginners to undestand concepts like DOM manipulation, setInterval and event handling. This project is fully responsive and optimised for mobile devices.

## Features

- Generates random Hex colours
- Start and Stop background colour animation
- Adjustable time delay using a range slider
- Displays current colour code in real-time
- Smooth background transition effect
- Prevent multiple intervals using button disabling
- Mobile Responsive Design ( works smoothly on all devices)

## Demo

- Clicking Start begins changing the background colour at a fixed interval
- Clicking Stop button stops the colour changes
- The range slider allow users to adjust the delay ( 200ms - 2000ms )
- The current colour is displayed in the hex format

## Tech Stack

- HTML5
- CSS
- Javascript

## Concepts Practiced

- setInterval() : for repeated execution
- clearInterval() : to Stop execution
- DOM Manipulation
- Event listeners
- Dynamic Styling with Javascript
- Preventing multiple intervals
- Responsive design using media queries
